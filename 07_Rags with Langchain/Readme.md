# RAG System with Pinecone and Ollama

This repository contains an implementation of a Retrieval-Augmented Generation (RAG) system using Pinecone and Ollama for efficient document retrieval and response generation.

## Folder Structure

- `notebook/` - Contains Jupyter notebooks for experimentation and testing.
- `rag_pc.py` - Script for integrating RAG with Pinecone deployed on streamlit
- `rag_ollama.py` - Script for using RAG with Ollama.


## Requirements

Make sure to install the required dependencies before running the scripts:

```bash
pip install -r requirements.txt
```

## How to Run

### Running the Streamlit App

```bash
streamlit run app.py
```

### Running the Scripts
Each script can be executed separately:

```bash
python rag_pc.py
python rag_ollama.py
```
